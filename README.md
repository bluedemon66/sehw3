# sehw3

Java 17 coursework project for a takeout ordering and delivery system.

The Maven project is in [lab3](lab3/README.md). It includes a console client, an HTTPS server, and an H2 database. Run the build and tests from that directory.

```sh
cd lab3
sh ./mvnw verify
```

[GitHub Actions](https://github.com/bluedemon66/sehw3/actions) runs the build, tests, style checks, and Javadoc generation on repository changes.
